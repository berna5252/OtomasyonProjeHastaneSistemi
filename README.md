# Otomasyon Proje Hastane Sistemi

Bu proje, C# Windows Forms kullanılarak geliştirilmiş bir hastane otomasyon sistemidir.

## Kullanılan Teknolojiler

- C#
- Windows Forms
- Visual Studio
- Git ve GitHub

## Proje İçeriği

Projede hastane otomasyonuna yönelik temel işlemler yer almaktadır. Hasta, doktor ve randevu süreçlerini yönetmeye yönelik masaüstü uygulaması olarak hazırlanmıştır.

## Amaç

Bu proje, Windows Forms ile masaüstü uygulama geliştirme, form tasarımı, temel veri yönetimi ve GitHub üzerinden proje paylaşımı pratiği yapmak amacıyla geliştirilmiştir.

## Kurulum

Projeyi çalıştırmak için:

1. Bu repoyu bilgisayarınıza indirin.
2. `WindowsFormsApp2.sln` dosyasını Visual Studio ile açın.
3. Projeyi derleyip çalıştırın.
